# 一、目标

## 用户的原话(2026-10-08,最终版)

> 让 agent 和人一样有**时间的概念**,可以看清行情随时间的演变,
> 看清历史上有没有**类似的大盘走势、行情走势、赚钱效应区间**,
> 就是会有**特征值去聚类分析**。
>
> ……让行情**有多维度可以让 agent 去看到,让他有机会去总结,然后去寻找类似的特征**。

配套的方法论来自用户认可的一段文章(「深刻 = 压缩」):

> 定理是结果。证明是路径。理论是地图。**概念是坐标系。**
> 真正的突破不是增加事实,而是**减少描述世界所需要的独立事实数量**。

权威设计文档:`docs/superpowers/specs/2026-09-05-time-river-endstate-design.md`
(已审,用户 09-05 确认「确实是这样」)。§4 最后一句:

> **历史推演当下 = 在河上找三维结构相似的窗口,只报后续事实与复现次数,不编概率数字。**

## 拆成可验收的四层

| 层 | 要什么 | 判据 |
|---|---|---|
| **1. 有数据** | 多条轨、多个维度上真的有值 | 不是 0 行、不是整维缺失 |
| **2. 不前视** | 每个历史时点只看得见那天已知的 | PIT 闸、`first_known_at`、缺口声明 |
| **3. 能被看见** | agent 拿到的是**空间**,不是别人排好的名次 | 逐维可见、相似性可分解、能回溯到表.列 |
| **4. 能被总结** | agent 自己找共同结构、命名、复用 | 簇能命名成概念(环境剧本)并进词表 |

## 两条被我搞错过、现已纠正的理解

| 我错在哪 | 用户纠正 |
|---|---|
| 把 **PIT** 当成目标 | PIT 只是第 2 层的一条约束,不是目标 |
| 把「量价十维 **vs** 授课框架」当成**比武** | 「**我的授课框架那个也是量价体系吧,没有哪个对哪个错,就是要综合起来**」 |

第二条尤其重要:授课框架的输入**全是量价**(赚钱效应 = 涨停数/承接/上涨比例/新高家数;
板块角色 = `pct_chg`/成交占比/涨停数/RPS/乖离)。它的价值**不是新数据源,
是同一批量价的另一种组合** —— 按那段文章这正是「换表示」,不是「加事实」。
**所以该合起来,不是比谁赢。**

## 其余硬约束

1. **不编概率数字** —— 只报后续事实与复现次数
2. **搭桥不并库** —— 教学标签与供应商标签命名空间严格分离(09-06 `56d1f5fa88d9`)
3. **自用不限个股**(2026-10-07)—— 红线是产品/合规决定,不约束所有者
4. **不上向量库 / embedding** —— 终局文档 §9 第 151 行已禁
5. **不报补丁数/测试数当进展** —— 报在世界上改变了什么
6. **「策略」一词禁用**,除非前面加「环境剧本」

## 第 3 层(能被看见)—— 本轮新做

### 多维对照镜头 `river_lens.py` ⬅️ **最新交付**

诊断 `[实测]`:`regime_block_for_llm` 递给 LLM 的是**成品答案**——
10 维 → 塌成 **1 个标量** → top K → 每行只渲染 **5 维的窗口均值**拼成字符串。
于是 agent **看不到多维、没法自己总结、不能决定「类似」是什么意思**。

镜头**不换算法不换距离不换权重**(全部复用 `market_regime_analogs` 三个函数),
只摊开三样:

| | |
|---|---|
| **① 维度结构** | 按历史 `\|r\|` 并组,回答「名义 N 维实际几组」。**同组一起吻合只算一件事吻合** |
| **② 距离分解** | 逐维 Δz、对齐/分歧、**独立组数** |
| **③ 距离地形** | `standout=(p5−nearest)/(p50−p5)`,回答「真的近」还是「矮子里拔将军」 |

`[实测]` 演示:构造一局,窗口 A 三个对齐维相关 **1.00**(一件事),
窗口 B 三个对齐维分属三组(三件事)。标量距离 **A=1.04 < B=1.13 ⇒ 旧视角选 A**;
镜头把「独立组数 **1 vs 3**」摆在表里。

纪律:只读;**不建第二套距离**(测试断言逐维贡献之和还原成同一个 `signature_distance`);
**不自己连库**(必须走 `build_daily_vectors`,那里强制 `knowledge_cutoff`,
另开取数路径=另开漏 PIT 的口子,有测试钉死);**特征集是参数**——
教学标签放完水直接加,不用改代码。
