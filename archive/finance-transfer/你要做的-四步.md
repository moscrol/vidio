## 第 2 步:重建教学表(**别删文件**)

```bash
python3 scripts/teaching_framework.py reset-teaching --yes
```

**为什么必须有这步:**我加了 `first_known_at` 列,而 `ensure_schema` 里全是
`CREATE TABLE IF NOT EXISTS` —— 不会改已存在的表。所以不做这步,第 3 步会直接报
「旁路库 schema 过期」。

**为什么不能 `rm` 那个文件:**同一个文件里还住着 legacy 的 `history_calendar`
和 `history_labels`(**那 273 MB 是它们的,教学表反而是 0 行**)。
那些**不是**从主库重算得回来的。这条命令只 DROP 10 张教学表。

输出里会有 `"legacy_untouched": true` 和 legacy 表的前后行数对照,可以自己核。
(教学表现在是 0 行,`--yes` 其实没丢任何东西。)
