# 短视频讲稿分镜工作流

## 目标

当用户输入一篇短视频讲稿时，Claude 需要把讲稿拆解成一份可直接交给剪辑师、数字人工具、AI 视频生成工具和剪映执行的 Markdown 分镜文件。

输出结果必须包含：

- 成片定位
- 口播压缩建议
- A-roll / B-roll / 动态图表使用判断
- 逐句分镜表
- B-roll 素材类型
- AI 生成 B-roll 提示词
- 动态图表设计
- 字幕设计
- 镜头语言
- 音效与音乐建议
- 剪映执行说明
- 素材清单
- 发布测试建议

---

# 一、输入格式

用户输入短视频讲稿时，Claude 应优先要求或识别以下信息：

```text
标题：
目标时长：60秒 / 75秒 / 90秒 / 未指定
出镜方式：真人 / 数字人 / 不出镜 / 未指定
内容类型：产业分析 / 财经逻辑 / 科技科普 / 商业案例 / 风险提示 / 未指定
工具：剪映数字人 / 剪映专业版 / 即梦 / 可灵 / Canva / 未指定
正文：
```

如果用户只给正文，也必须继续执行，不要反复追问。

默认设置：

```text
目标时长：60-75秒
成片比例：9:16
分辨率：1080x1920
出镜方式：数字人/真人 + B-roll + 动态图表
固定数字人工具：剪映数字人
剪辑工具：剪映专业版
B-roll 工具：即梦 / 可灵 / 真实素材库
图表工具：Stitch + Remotion（代码生成） / 剪映模板（手动制作）
```

---

# 二、固定分析流程

Claude 必须按以下顺序分析。

## 1. 判断内容类型

先判断讲稿属于哪类：

```text
认知颠覆型
产业链拆解型
技术卡点型
量产进展型
投资风险型
三点框架型
商业案例型
```

并说明该类型最适合的视频形态。

## 2. 判断成片形式

在以下形式中选择主形态：

```text
数字人/真人口播 + B-roll + 动态图表
素材混剪 + AI 配音 + 动态字幕
绿幕讲解 + 图表
动态图文为主
剧情化/情景化
```

必须给出比例：

```text
A-roll：xx%
B-roll：xx%
动态图表/文字卡：xx%
```

## 3. 压缩口播稿

如果原稿过长，输出一版适合短视频的压缩稿。

要求：

```text
保留核心观点
删掉重复解释
强化前3秒钩子
每句话更口语化
控制在目标时长内
结尾必须有互动问题或结论金句
```

## 4. 切分句子

把讲稿拆成可执行的分镜单元。

每个单元最好控制在：

```text
2-6秒
1个明确画面动作
1个核心信息点
```

## 5. 判断 A-roll / B-roll / 动态图表

按规则判断每句适合哪种画面。

### A-roll 适用场景

```text
核心观点
反常识判断
重要转折
风险提示
结论金句
评论引导
需要建立信任的句子
```

### B-roll 适用场景

```text
动作描写
产品展示
工厂场景
真实案例
技术细节
视觉冲击
场景切换
```

### 动态图表适用场景

```text
数字
比例
价格
时间线
流程
对比
产业链结构
判断框架
风险路径
```

# 四、逐句分镜表字段说明

## 镜号

每个镜头必须编号，方便剪辑沟通和返工。

格式：

```text
01
02
03
```

## 时间

估算每句在成片中的时间段。

格式：

```text
0-3s
3-7s
7-12s
```

## 口播文案

填写该镜头对应的口播句子。

如果原句太长，必须压缩成适合口播的版本。

## 画面类型

只能从以下类型中选择或组合：

```text
A-roll
B-roll
动态图表
A-roll + 图表
B-roll + 图表
文字卡
```

## 场景

写清楚画面发生在哪里，不能只写“素材”。

常用场景：

```text
居家书房
知识博主工作室
现代工厂
汽车装配线
智能仓库
实验室
发布会现场
展会现场
火箭发射场
卫星制造车间
太空轨道示意
新闻/网页截图界面
抽象概念空间
```

场景选择规则：

```text
观点/结论：居家书房或知识博主工作室
量产/订单：工厂、仓库、装配线
技术难点：实验室、零部件特写环境
公司进展：发布会、展会、官网/新闻截图
抽象概念：AI生成概念空间或动态图表背景
```

## 景别

每个镜头必须标注景别。

常用景别：

```text
大远景：交代宏大场景，例如火箭发射场、工厂外景
远景：展示完整环境和主体关系，例如整条产线
全景：展示主体全身动作，例如机器人行走、搬箱子
中景：人物上半身或机器人半身，适合讲解
近景：人物脸部/胸像，适合观点、转折、结论
特写：手、零部件、按钮、数据、价格数字
微距：齿轮、电机、传感器、机械手细节
```

景别选择规则：

```text
开头钩子：近景或特写
动作展示：全景或中景
工厂量产：远景或全景
技术细节：特写或微距
数据强调：特写/数字卡
结论金句：近景
```

## 机位/视角

每个镜头必须标注视角。

常用视角：

```text
正面平视：数字人/真人讲观点，最稳
侧面45度：解释图表或与右侧图文搭配
俯拍：展示桌面、图纸、产线布局、流程
仰拍：增强火箭、机器人、巨大设备的力量感
主观视角：模拟用户/机器人看到的画面
过肩视角：看屏幕、看产线、看数据
分屏视角：做 Demo vs 产品、研发 vs 量产 对比
鸟瞰视角：工厂、发射场、城市、星座网络
```

视角选择规则：

```text
A-roll观点：正面平视
A-roll讲图表：侧面45度或人物偏左
B-roll动作：平视或跟拍
B-roll宏大场景：仰拍/鸟瞰
B-roll技术细节：特写平视或微距
图表对比：分屏视角
```

## 镜头运动

每个镜头必须说明是否运动，怎么运动。

常用镜头运动：

```text
固定镜头：稳定讲观点
轻微推近：强调观点或金句
轻微拉远：从细节拉到全局
横移：展示工厂产线或多个节点
跟拍：跟随机器人/机械臂动作
俯冲/上升：表现宏大场景或转场
快切：展示多个动作或冲击画面
慢推：营造专业感和悬念
画面压暗：进入风险或反转
数字缩放：剪映关键帧 100%→105%
```

运动选择规则：

```text
观点句：固定镜头或轻微推近
反转句：固定后突然切图表/闪白
动作列举：快切
工厂场景：横移或慢推
技术细节：微距固定或慢推
风险提示：画面压暗，少用花哨运动
结论金句：轻微推近，留停顿
```

## 构图/画面重点

每个镜头应明确主体在画面中的位置，以及用户第一眼应该看哪里。

常用构图：

```text
居中构图：适合开头强观点、结论金句
左侧人物 + 右侧图表：适合数字人讲解
左右分屏：适合对比，例如 Demo vs 产品
上方标题 + 下方素材：适合大字卡点
中心大数字：适合数据冲击
前景主体 + 背景工厂：适合产业场景
局部特写占满屏：适合技术细节
三卡片纵向排列：适合三点框架
```

构图选择规则：

```text
A-roll讲观点：人物居中或略偏左
A-roll配图表：人物左侧，右侧留白
B-roll动作：主体居中，避免字幕挡住动作
B-roll技术特写：细节居中放大
动态图表：核心数字/关键词居中
对比图：左右均衡，中间放 VS 或 ≠
```

## 转场

每个镜头必须写清楚转场方式。

常用转场：

```text
硬切：最常用，适合知识类短视频
快切：适合动作列举和节奏加速
闪白：适合反转、观点切换
擦除：适合图表进入
推拉转场：适合从 A-roll 切 B-roll
匹配剪辑：用相似动作或形状连接两个画面
画面压暗：适合进入风险段
音乐停顿切：适合死亡谷、风险、结论
```

转场选择规则：

```text
A-roll到B-roll：硬切或推拉
B-roll动作组：快切
观点反转：闪白或音乐停顿切
进入图表：擦除或滑入
进入风险：画面压暗
结尾互动：硬切回 A-roll
```

## 素材状态

每个 B-roll 或图表镜头应标注素材状态，便于执行。

素材状态类型：

```text
已有素材：用户已有或可直接使用
需搜索素材：需要找官方/公开/素材库
需 AI 生成：需要即梦/可灵生成
需剪映模板：用剪映模板制作
需 Canva 制作：用 Canva 做成图表后导入
需自制截图：官网、新闻、财报、研报截图
```

素材状态判断规则：

```text
具体公司真实画面：优先需搜索素材
通用工厂/仓库/城市：优先素材库或 AI 生成
抽象概念：优先 AI 生成或动态图表
数据/流程/对比：优先剪映模板或 Canva
需要事实背书：优先截图或公开来源
```

## 画面内容

写清楚画面应该是什么。

例如：

```text
数字人近景直视镜头，右侧留白放关键词。
机器人跳舞、翻跟头、端咖啡快切。
工厂产线、机器人搬箱子、机械臂拧螺丝。
```

## 字幕/图表

写清楚屏幕上出现的文字或图表内容。

例如：

```text
大字：Demo ≠ 产品
关键词：进工厂 / 搬箱子 / 拧螺丝 / 客户付钱
```

## 镜头语言

描述剪辑和镜头运动。

常用表达：

```text
近景直视
轻微推进
快切
闪白转场
左右滑入
关键词弹出
画面压暗
整体轻微放大 100%→105%
```

## 音效/音乐

写清楚音效节点。

常用：

```text
低频冲击
whoosh
click
pop
警告音
音乐短暂停顿
重击音
```

## 剪映执行

必须写到可执行层面。

例如：

```text
添加文字模板“科技标题”，关键词设为黄色，入场动画选择“弹入”，时长0.3秒。
使用左右对比模板，左侧红色Demo，右侧黄色产品，中间放大“≠”。
```

# 五、动态图表模板库

Claude 应优先从以下模板中选择。

## 1. 左右对比模板

适用：

```text
Demo ≠ 产品
研发成功 ≠ 量产
样品 ≠ 工厂产品
```

剪映做法：

```text
搜索“对比 / VS / 左右对比 / 科技对比”模板。
左侧设为红色或深灰，右侧设为黄色或绿色。
中间用大号 ≠ 或 VS。
左右卡片滑入，中间符号弹出。
```

## 2. 数字冲击卡

适用：

```text
73%
2-3万美元
8小时
百万台
```

剪映做法：

```text
搜索“数据 / 数字 / 科技数字 / 财经数字”。
数字用黄色大字，解释文字用白色小字。
给数字添加放大入场和轻微缩放关键帧。
```

## 3. 流程图模板

适用：

```text
送样 → 定点 → 批量 → 高利润
研发 → 量产 → 商业化
```

剪映做法：

```text
搜索“流程 / 阶段 / 步骤 / 路径”。
节点依次出现，当前节点变黄色。
每个节点出现时加 click 或 pop 音效。
```

## 4. 时间线模板

适用：

```text
样品时代 → 产品时代
2026 量产元年
```

剪映做法：


# 六、A-roll / B-roll 选择规则

## 用 A-roll 的句子

如果句子承担以下功能，优先 A-roll：

```text
开头钩子
反常识观点
核心判断
风险警告
总结金句
互动提问
```

A-roll 镜头建议：

```text
数字人/真人中近景
人物略偏左
右侧留白
语气冷静但有判断力
关键句轻微停顿
```

## A-roll 语气、语调、语速判断规则

Claude 在逐句分镜表中，必须为每一个 A-roll 镜头额外写明：

```text
语气：
语调：
语速：
停顿：
重读词：
情绪强度：
```

### 1. 开头钩子型

适用句子：

```text
反常识开头
强判断
直接否定用户原有认知
```

示例：

```text
机器人不是来跳舞的，是来干活的。
真正的拐点，不是发布会，而是订单。
```

执行规则：

```text
语气：笃定、直接、有冲击力
语调：前半句略压低，关键判断抬高
语速：中快，不能拖
停顿：核心反差词前后各停 0.2-0.4 秒
重读词：不是、而是、真正、拐点
情绪强度：中高
剪映执行：A-roll 近景开场，镜头轻推 100%→105%，加低频冲击音，大字标题同步弹出
```

### 2. 反常识转折型

适用句子：

```text
但告诉你一个反直觉的事实
但真相不是这样
问题恰恰出在这里
```

执行规则：

```text
语气：压低、冷静、制造悬念
语调：先放慢，再在结论处加重
语速：中速偏慢
停顿：在“但”“真相是”“反直觉”后停 0.3 秒
重读词：反直觉、真相、Demo、问题
情绪强度：中
剪映执行：数字人画面短暂停留，背景音乐降低 10%-20%，结论词出现时加 click 或重击音
```

### 3. 解释拆解型

适用句子：

```text
解释概念
拆解逻辑
说明原因
介绍三个信号/四个步骤
```

执行规则：

```text
语气：清楚、稳定、像在讲明白一件事
语调：平稳，不要过度情绪化
语速：中速
停顿：每个信息点之间停 0.2 秒
重读词：第一、第二、核心、关键、原因
情绪强度：中低
剪映执行：A-roll 可放左侧，右侧同步出现关键词卡片或小图表
```

### 4. 数据强调型

适用句子：

```text
价格
比例
时间
数量
市场规模
成本
```

执行规则：

```text
语气：专业、准确、强调可信度
语调：数字前放慢，数字本身重读
语速：中速偏慢
停顿：数字前停 0.2 秒，数字后停 0.3 秒
重读词：具体数字、单位、目标价、占比、百万台
情绪强度：中
剪映执行：数字人说数字时切入数字冲击卡，数字用黄色大字，添加放大入场
```

### 5. 风险提示型

适用句子：

```text
不要误判
不构成投资建议
送样不等于订单
股价可能已经提前定价
```

执行规则：

```text
语气：严肃、克制、提醒式
语调：略低，结尾不要上扬
语速：中慢
停顿：风险词前后停 0.3-0.5 秒
重读词：不等于、风险、跳票、回撤、不要
情绪强度：中高但不煽动
剪映执行：画面压暗，风险词用红色，添加警告音或低频音，不要使用欢快转场
```

### 6. 结论金句型

适用句子：

```text
一句话总结
可以被用户记住或转发的判断
```

执行规则：

```text
语气：笃定、收束、有记忆点
语调：前半句平稳，最后关键词下压
语速：中慢
停顿：金句前停 0.3 秒，金句后留 0.5 秒
重读词：样品、产品、订单、量产、死亡谷
情绪强度：中高
剪映执行：回到 A-roll 正面，叠加大字金句，BGM 短暂停顿后恢复
```

### 7. 互动提问型

适用句子：

```text
你怎么看？
你觉得会先进入工厂还是家庭？
评论区聊聊。
```

执行规则：

```text
语气：自然、开放、像真实提问
语调：结尾轻微上扬
语速：中速偏慢
停顿：问题说完后留 0.5 秒
重读词：你觉得、先、还是
情绪强度：中
剪映执行：数字人正面中景，字幕做成问题卡，结尾不要立刻切黑，留半秒反应时间
```

## 动态图表生产管线

动态图表的"代码生成"部分通过 `stitch-to-video` skill 完成，流程如下：

```text
分镜表图表描述
  ↓ 识别视频题材 → 确定视觉风格方向
  ↓ enhance-prompt → 注入题材视觉风格，生成 Stitch 提示词
  ↓ Stitch 生成图表设计稿
  ↓ 翻译为 Remotion 组件（结构复用现有模板，视觉跟 Stitch 走）
  ↓ 渲染 MP4 输出
```

**题材决定视觉风格，图表类型决定结构：**

| 题材 | 视觉方向 | 配色基调 |
|------|---------|---------|
| 机器人/工业 | 精密工程仪表盘 | 钢蓝、琥珀、深碳 |
| 金融/财经 | 交易终端/市场面板 | 红宝石、金色、深海军蓝 |
| 科技/消费电子 | 产品发布会风格 | 白、石板灰、单色强调 |
| 新能源/汽车 | 能源仪表盘 | 绿、电光蓝、暗色 |
| 医药/生物 | 实验室级精密 | 蓝绿、白、冷中性 |
| 通用知识科普 | 平衡、亲和 | 蓝色强调、暖灰 |

**与剪映模板的关系：**
- "代码生成"图表 → 走 `stitch-to-video` 管线（Stitch + Remotion）
- "剪映模板"图表 → 走剪映手动制作（时间线等需要精确对齐口播的图表）
- 每个图表在分镜表中必须标注生产方式："代码生成"或"剪映模板"

## 动态图表制作细化规则

Claude 必须为每个动态图表写清楚：

```text
图表目的：让用户记住什么
图表类型：左右对比 / 数字卡 / 流程图 / 时间线 / 三点框架 / 产业链图 / 占比图
出现时机：对应哪句口播
生产方式：代码生成（stitch-to-video） / 剪映模板（手动制作）
屏幕文字：具体写什么
颜色规则：哪些词黄、哪些词红、哪些词白
动画方式：滑入、弹出、擦入、放大、依次亮起
音效：click、pop、whoosh、低频重击、警告音
制作步骤：代码生成→由 stitch-to-video skill 自动完成；剪映模板→逐步写明剪映操作
复用建议：是否保存为模板
```

### 1. 左右对比图制作步骤

适用：

```text
Demo ≠ 产品
研发成功 ≠ 量产
样品 ≠ 工厂产品
```

剪映步骤：

```text
1. 在时间线上定位到对应口播句。
2. 添加深灰或黑色半透明背景。
3. 添加左侧矩形卡片，写反方/旧认知，例如 Demo。
4. 左侧关键词使用红色或灰白色。
5. 复制卡片到右侧，写正方/新认知，例如 产品。
6. 右侧关键词使用黄色或绿色。
7. 中间添加大号“≠”或“VS”。
8. 左卡片设置“向右滑入”，右卡片设置“向左滑入”。
9. 中间符号设置“弹入/放大”。
10. 三个元素出现时分别加 whoosh、whoosh、低频重击。
11. 图表整体添加轻微缩放关键帧 100%→105%。
12. 做完后复制保存为“左右对比模板”。
```

### 2. 数字冲击卡制作步骤

适用：

```text
73%
2-3万美元
8小时
百万台
```

剪映步骤：

```text
1. 添加深色半透明卡片作为底。
2. 添加大号数字，颜色设为黄色。
3. 添加解释小字，颜色设为白色。
4. 如果数字代表风险或否定，旁边加红色提示符号。
5. 数字设置“放大/弹入”动画，时长 0.2-0.4 秒。
6. 小字设置“上滑/淡入”动画。
7. 数字出现时加 pop 或低频冲击音。
8. 数字停留至少 1.5 秒，保证用户看清。
9. 画面整体轻推 100%→103%。
10. 保存为“数字冲击卡模板”。
```

### 3. 流程图制作步骤

适用：

```text
送样 → 定点 → 批量 → 高利润
研发 → 量产 → 商业化
```

剪映步骤：

```text
1. 根据手机竖屏选择横向或纵向排列；节点超过 4 个时优先纵向。
2. 每个节点做成独立文字卡片。
3. 节点之间添加箭头。
4. 默认节点为深灰底白字。
5. 当前讲到的节点变为黄色底或黄字。
6. 节点按口播顺序依次出现。
7. 每个节点出现时加 click 音效。
8. 讲到风险节点时，把该节点短暂变红。
9. 最后全流程停留 1 秒，方便用户截图/收藏。
10. 保存为“流程图模板”。
```

### 4. 时间线制作步骤

适用：

```text

技术发展阶段
```

剪映步骤：

```text
1. 添加一条横向线或纵向线作为时间轴。
2. 左侧/上方写过去阶段，右侧/下方写当前或未来阶段。
3. 关键年份使用黄色。
4. 风险断层或死亡谷使用红色。
5. 时间线设置“擦入”动画。
6. 阶段标签按顺序淡入。
7. 关键节点出现时加 click。
8. 风险节点出现时加低频重击或警告音。
9. 如果讲“刚开始”，不要让产品时代显得已经完全成熟，可用半透明或虚线。
10. 保存为“时间线模板”。
```

### 5. 三点框架图制作步骤

适用：

```text
真实产线
真实订单
真实替代
```

剪映步骤：

```text

2. 下方纵向排列三张卡片。
3. 每张卡片左侧写 01/02/03。
4. 右侧写关键词。
5. 每讲到一点，对应卡片变黄或放大 105%。
6. 未讲到的卡片保持灰色。
7. 三点讲完后全部亮起。
8. 加轻微 click 音效和最终总结重击音。
9. 保存为“三点框架模板”。
```

### 6. 产业链/结构图制作步骤

适用：

```text
整机
零部件
执行器
传感器
减速器
丝杠
```

剪映步骤：

```text
1. 先确定中心主体，例如“人形机器人”或“商业航天”。
2. 中间放主体图标或简化轮廓。
3. 周围放 3-6 个环节卡片。
4. 用线条或箭头连接主体与环节。
5. 当前讲到的环节高亮黄色。
6. 非重点环节降低透明度。
7. 如果有价值量或重要程度，用数字卡叠在对应环节旁边。
8. 每个环节出现时加 click。
9. 重点环节出现时加放大和低频音。
10. 保存为“产业链结构模板”。
```
