## 4. 字幕怎么做

### 4.1 新手最简单做法

1. 选中口播音频或视频。
2. 使用剪映“智能字幕 / 识别字幕”。
3. 生成后检查错别字。
4. 字幕位置放在底部，但不要太靠下。

### 4.2 字幕样式建议

```text
字体：剪映默认黑体 / 思源黑体 / 粗体
颜色：白色
关键词：金色或黄色
描边：深蓝或黑色
每行字数：不超过 16-18 个汉字
```

注意：

```text
不要让字幕挡住 PNG 卡片的主标题。
图文卡出现时，可以减少底部字幕，只保留关键词。
```

## 5. BGM 和音量

### 5.1 BGM 类型

剪映搜索：

```text
科技感
纪录片
电子
工业
未来感
```

不要选：

```text
太燃的影视预告片音乐
太吵的 EDM
太情绪化的悲伤音乐
```

### 5.2 音量建议

```text
口播音量：100%
BGM 音量：15%-25%
B-roll 原声：0%-20%，多数时候可以静音
音效：30%-50%
```

如果听不清口播，优先降低 BGM。

---

## 6. 转场原则

新手不要用花哨转场。

只用这三种：

```text
硬切
淡入淡出
轻微推近
```

不要用：

```text
旋转
翻页
碎片
炫光
漫画转场
```

原因：

```text
Industry 7View 的风格是克制、研究感、可信，不是短剧和娱乐剪辑。
```

## 9. 粗剪验收清单

导出前检查：

- [ ] 开头 3 秒是否能看懂“商业航天 ≠ 发火箭”。
- [ ] 每张卡是否至少停留 2.5 秒。
- [ ] 04 商业闭环是否停留足够久。
- [ ] 字幕是否挡住卡片主标题。
- [ ] 口播是否听得清。
- [ ] BGM 是否太吵。
- [ ] B-roll 是否过度科幻或像素材库广告。
- [ ] 结尾是否有互动问题。
- [ ] 是否保留“不构成投资建议”。
- [ ] 全片是否保持 Industry 7View 的克制研究感。

## 10. 第一版不要追求完美

第一版粗剪的目标不是发布，而是验证：

```text
这套卡片放进视频里是否舒服
口播和图文卡节奏是否匹配
B-roll 是否需要增加或减少
用户能不能一眼看懂核心观点
```

如果粗剪 OK，再进入下一步：

```text
把 04 商业闭环、05 跟踪清单等卡片做成 Remotion 动态模板。
```
