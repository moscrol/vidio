# 即梦 A-roll × 小研 B-roll 试片设计

## 目标

使用用户认可的 28.816667 秒即梦数字人 A-roll，制作一支短试片，验证新版数字人的停顿、表情和动作能否与现有小研全屏 B-roll 自然结合。

本试片只验证融合效果，不扩展为完整半导体成片。

## 输入

### A-roll

文件：

`/Users/a77/Downloads/jimeng-2026-06-10-2932-正面中近景，专业克制的财经研究员口播。自然看向镜头，动作少而准确。 反问时轻微抬....mp4`

参数：

- 时长：28.816667 秒
- 画幅：704×1248
- 帧率：60fps
- 音频：AAC，44.1kHz，双声道

### 小研 B-roll

复用 `SemiconductorFinishedV2` 的视觉系统和固定资产：

- 门槛放大镜。
- 产线风险多米诺。
- 验证链开头。
- A-roll 黑白素描分身。
- 暖白纸张、黑色手绘线、红色风险、蓝色认证。

## 时间结构

### 0–5 秒：A-roll 建立人物

- 新即梦数字人全屏。
- 保留原声。
- 只放克制品牌标识，不增加大组件。
- 画面按竖屏中心裁切适配到 720×1280。

### 5–11 秒：小研门槛画布

- 切入“真正门槛不在发布会”全屏 B-roll。
- 使用晶圆厂大门、小研指图表、敢不敢用的视觉关系。
- 音频继续使用 A-roll 原声。

### 11–15 秒：A-roll 转折

- 回到数字人。
- 利用人物视线、停顿和表情承担“为什么”的转折。
- 不叠大型卡片。

### 15–21 秒：小研风险多米诺

- 切入设备、良率下降、晶圆污染、产线减速。
- 风险节点按音频节奏依次强调。
- 人物分身在画面中保持辅助角色，不遮挡字幕。

### 21–26.5 秒：验证链开头

- 展示“能跑通 → 敢使用”的前半段。
- 不展开完整七步，只验证三段式验证链的起势。
- 小研沿验证链移动。

### 26.5–28.816667 秒：A-roll 收尾

- 回到数字人。
- 保留片尾自然停顿。
- 不额外添加总结口号。

## 音频与字幕

- 使用即梦 A-roll 原音频作为唯一主音频。
- 不改变口播语速、音高和停顿。
- 先使用本地 Whisper 转录获取实际时间戳。
- 小研全屏段重新绘制字幕。
- A-roll 若未烧录字幕，则统一使用同一字幕层；若已烧录，则避免重复。

## 视觉适配

- 输出 720×1280、30fps。
- A-roll 使用 cover 裁切，避免拉伸。
- 右下角即梦水印通过安全裁切或浅色品牌覆盖处理，不做明显模糊块。
- A-roll 与小研之间使用 0.3–0.45 秒纸张擦入/擦出。
- 不添加背景音乐，避免干扰口播节奏判断。

## 验收标准

- 总时长与输入 A-roll 一致，误差不超过 0.05 秒。
- 原音频完整保留且音画同步。
- A-roll 与小研 B-roll 至少完成四次自然切换。
- 数字人的停顿处不被无意义动画填满。
- 小研画面与口播含义基本同步。
- 无字幕重叠、人物遮挡、画面拉伸或黑边。
- 输出 H.264 视频和 AAC 音频。
