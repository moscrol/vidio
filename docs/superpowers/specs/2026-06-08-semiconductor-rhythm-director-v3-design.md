# 半导体设备成片 v3 节奏强化设计

## 目标

在不重录 A-roll 音频、不改变核心产业逻辑的前提下，将现有 90.2 秒成片从“平铺直叙的信息解释”升级为有起承转合的导演版。

这次强化的核心不是增加更多内容，而是重排能量曲线：

- 开头立误区。
- 前段用风险加压。
- 中段把验证链从流水账改成三段推进。
- 认证周期处制造停顿和转折。
- 结尾用否定、盖章和兑现完成回收。

## 叙事结构

采用用户确认的 A 方案：“问题 - 压力 - 反转 - 兑现”。

### 1. 问题：很多人误会了国产化

时间范围：0-11.4 秒。

目的：

- 快速建立观众熟悉的误区：“造出来了 = 国产化成功”。
- 立刻用“晶圆厂敢不敢用”推翻误区。

节奏处理：

- A-roll 开场保留真人信任感。
- 切入小研画布后，“发布会”“实验室样机”快速让位。
- “晶圆厂”大门不要慢慢解释，要作为第一记重锤出现。
- “敢不敢用？”需要有一次盖章式强强调。

### 2. 压力：设备不稳定会推倒产线

时间范围：11.4-21 秒。

目的：

- 回答“为什么敢不敢用这么重要”。
- 把风险从单点故障放大到整条产线。

节奏处理：

- “为什么？”后留一个很短的呼吸，不超过 0.25 秒。
- 风险多米诺按三拍推进：良率下降、晶圆污染、产线减速。
- 每一拍要有红色警告点或震动，不做平滑淡入。
- 小研动作从观察改为“试图扶住风险”，形成紧张感。

### 3. 承接：验证链不是流程图，是距离

时间范围：21-49.166 秒。

目的：

- 保留验证链的完整性，但避免 28 秒连续平铺。
- 让观众感受到“能跑通”和“能赚钱”之间真的很远。

节奏处理：

验证链拆成三段：

1. 能跑通：样机、客户验证。
2. 敢使用：小批量导入、长期跑产。
3. 能赚钱：批量订单、收入确认、毛利兑现。

每段需要不同的视觉节奏：

- 第一段偏快，像起跑。
- 第二段变重，节点更密，强调稳定运行。
- 第三段收紧，订单、收入、毛利连续落下，形成兑现感。

关键要求：

- 不再把七个节点用同一种卡片节奏逐个展示到底。
- 在“长期跑产”附近加入一次小停顿，让观众意识到真正难点在真实工艺里。
- “最后，才是...”要明显比前面更有重量。

### 4. 转折：壁垒不是参数，而是认证与信任

时间范围：49.166-68.066 秒。

目的：

- 从前面的验证链，转向研究判断框架。
- 用认证周期把行业难点压实。

节奏处理：

- A-roll 回来做呼吸段，不能再叠太多信息。
- 天平画布要形成明显反差：参数很多，但认证与信任更重。
- “12-24 个月”出现时要全屏化、数字化、有停顿。
- 数字出现后加入 0.3-0.4 秒视觉停顿，再进入“三个问题”。

这里是全片最重要的转折点。它不是新信息堆叠，而是告诉观众：研究这个行业的方法变了。

### 5. 合：三个问题与商业兑现

时间范围：68.066-90.2 秒。

目的：

- 把产业解释收束成可记住的研究框架。
- 结尾从“题材”落到“生意”。

节奏处理：

- 三道检查门逐门通过，不能一次性展示完整 checklist。
- 每道门通过时要有明确的勾选、开门或通行反馈。
- “真正的终点不是我们做出来了”要先做否定，不要直接进入正向结论。
- 结尾按四拍盖章：敢用、跑稳、复购、毛利兑现。
- 最后一帧回到 A-roll，让真人完成品牌信任回收。

## 时间轴调整原则

总时长保持 90.2 秒，不改 A-roll 音频。

允许调整的是：

- 小研画布内部动画的入场节奏。
- 组件内部的停顿、震动、盖章和线条绘制速度。
- 字幕断句的视觉呈现。
- 转场纸张的方向和强弱。
- A-roll 与画布之间的能量对比。

不允许调整的是：

- 不得重录或拉伸音频。
- 不得删除核心产业逻辑。
- 不得让字幕与 A-roll 烧录字幕重复出现。
- 不得把节奏强化做成过度短视频模板，保留金融研究的克制感。

## 视觉与动效规则

### 强调方式

优先使用这些手绘式强调：

- 红色警告圈。
- 蓝色认证线。
- 手写盖章。
- 纸张停顿。
- 放大镜扫过。
- 节点轻微震动。
- 线条加粗或描边二次绘制。

避免使用：

- 大面积霓虹光效。
- 纯科技 HUD。
- 大量飞入卡片。
- 过度弹跳的娱乐化动效。

### 停顿方式

停顿不使用黑场。使用暖白纸面、短暂停止线条生长、字幕短句留白来完成。

关键停顿点：

- “为什么？”后 0.15-0.25 秒。
- “长期跑产”附近 0.25-0.35 秒。
- “12-24 个月”后 0.3-0.4 秒。
- “不是我们做出来了”后 0.25-0.35 秒。

### 字幕语气

字幕内容不大改，但视觉断句要更有顿挫。

示例：

- “为什么？”单独出现。
- “不只是技术参数”与“而是客户认证和产线信任”要形成反差。
- “不是我们做出来了”要先显示否定态，再进入正向盖章。
