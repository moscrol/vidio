# 跨平台内容原则

## 起号

1. 第一条不做产品介绍 / 功能清单 / 下载引导
2. 前 10～15 条：痛点 + 方法 + 开发日记；零硬广
3. 完播与评论优先于播放量；数据差就改钩子，不连发广告

## 金融合规（硬红线）

- 不荐股、不给买卖点、不承诺收益
- 不写「稳赚 / 内幕 / 跟单 / AI 预测大盘」
- 产品只作为「效率工具 / 工作流」出现，不做投资建议

## 内容公式（默认）

```
0–3s  痛点钩子（可搜索词）
3–20s 方法或反常识
结尾   开放问题逼评论（不问关注、不推下载）
```

## 转化节奏

- 主页简介后期再挂工具入口
- 每 5～8 条最多 1 条「我的工作流」软露产品界面
- 用户主动问「用什么」再在评论区回应
