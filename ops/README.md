# 短视频运营（ops）

顾问工作区：策略、脚本、数据复盘。不放重生产管线代码（那是 `industry7view-card-lab/`）。

## 目录

```
ops/
├── README.md                 # 本文件
├── knowledge/                # 可复用知识资产（钩子 / 算法 / skill 目录）
├── shared/                   # 跨平台通用原则（定位、合规、内容公式）
└── douyin/                   # 抖音
    ├── strategy.md           # 账号定位与起号策略
    ├── content-calendar.md   # 内容排期
    ├── scripts/              # 可拍脚本（按 day / 主题）
    ├── reviews/              # 发布后数据复盘
    └── assets/               # 封面文案、资料区文案等轻资产
```

知识入口：[`knowledge/README.md`](./knowledge/README.md)

## 协作方式（顾问模式）

1. 在本目录写清定位、选题、脚本
2. 你拍摄 / 发布
3. 把数据贴进 `reviews/` 或对话里
4. 顾问根据完播 / 评论 / 关注调整下一轮
