## 口播全文（提词器 · 约 28s）

> 防幻觉，不是要求 AI 永远不说错。  
> 是把 AI 的输出，先当成**候选稿**——像记者写的稿，不能直接当终审事实。  
>  
> 第一性很简单：大模型是在**预测下一个词**，流畅不等于真实；  
> 外面的数据、时间、公告，它自己证明不了。  
> 就算数字对了，「所以主线切换、明天必涨」——那是解释和预测，不能一起升级。  
> 能给意见，也不等于有**决策权**。  
>  
> 所以我做研究 Agent 时，按五层挡：  
> **生成 → 外部证据 → 代码校验 → 历史重放 → 人工金标准**；  
> 外面再加一道：**权限**——没验收的分数，不能自动写库、不能当硬闸门。  
>  
> 客服、知识库、代码助手，都一样：先问它是事实、解释，还是动作。  
>  
> 你现在信 AI 的哪一层？评论区聊聊。

**字数**：约 220 字 · 正常语速 ~28–32s（不含情绪段）

## 屏幕卡片文案（可直接做 HTML/剪映）

### 卡1
- 主：生成不是真相  
- 副：AI 是快记者 · 输出先当候选稿  

### 卡2（第一性 · 竖向箭头）
```
流畅 ≠ 真实
→ 外部证据
→ 代码可重复校验
→ 历史时点重放
→ 人工金标准
→ 权限：未验收 ≠ 自动决策
```

### 卡3（五层 + 权限）
```
① 生成器     写候选
② 数据证据   对齐外部记录
③ 确定性校验 同输入同结果
④ 历史重放   禁止偷看未来
⑤ 人工金标准 模糊标签边界
────────────
权限 authority  能否自动动作
```

### 卡4
```
「成交额 +20%」     → 可核验事实
「健康分歧」       → 仍是解释
「明天会回流」     → 预测
「A 最强」         → 选择/建议
不要整句打一个对错
```
