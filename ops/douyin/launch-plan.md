## 2. 核心判断：以什么形式起号

### 2.1 不推荐

| 形式 | 原因 |
|------|------|
| 第 1 条再发 FinHot 60s 产品片 | 已踩过；完播差、像广告 |
| 第 1 条发完整 Deep Fomo 60–75s 流式报告 | 太长，中段完播崩；像录屏说明书 |
| 纯 Industry 7View 产业号起号 | 内容重、与产品转化断层；小研 IP 与 Agent 品牌分裂 |
| 双号并行（产业号 + 产品号） | 0 粉阶段分散精力 |
| 「评论区报票 / 深挖+股票名」当冷启动 CTA | 合规与限流风险高；像荐股工作室 |

### 2.2 推荐形态（一句话）

> **一个账号、一个人设、三种片型：  
> 「Deep Fomo 研究过程短片」为主 ·「信息减噪方法」为桥 ·「独立开发日记」为信任。  
> FinHot 与完整 Agent 产品片只做后期软植入。**

人设统一：

> **做 A 股研究效率工具的独立开发者**  
> 副标可写：Deep Fomo · 研究先于情绪（资料区，不硬广）

### 2.3 为什么主推 Deep Fomo 短片而不是 FinHot

| 维度 | Deep Fomo 30s 剪 | FinHot 60s Demo |
|------|------------------|-----------------|
| 钩子 | 结论/情绪/反差开场（anim7 已有） | 功能罗列，钩子弱 |
| 差异化 | 思考过程可见，像「研究员在屏幕上跑」 | 工具界面，竞品多 |
| 产能 | `deepfomo-kit`：content.md → 一键出片 | 每次改 HyperFrames 成本高 |
| 转化逻辑 | 用户先信「研究质量」再问工具 | 用户先要信「信息过载痛」 |
| 与仓库纵深 | 直接吃 finance-workspace + KB 产出 | 只覆盖信息层一层 |

FinHot **不是放弃**，而是第二层产品故事：「读资讯」vs「做研究」——账号成熟后再讲双产品。

## 3. 推荐内容矩阵（前 30 天）

### 3.1 片型配比

| 片型 | 占比 | 时长 | 制作方式 | 目的 |
|------|------|------|----------|------|
| **A. 研究过程条** | 50% | 20–35s | deepfomo-kit 出 30s 剪，或从长报告截「结论钩子+1 个证据段」 | 完播 + 专业标签 |
| **B. 方法/认知条** | 30% | 15–30s | 口播或大字+少量录屏；可不露产品名 | 搜素流量 + 共鸣 |
| **C. 开发日记** | 15% | 15–25s | 真人/录屏：本地数据、证据门、为什么不做荐股机器人 | 信任 |
| **D. 软产品** | ≤5%，**第 16 条后** | 20–25s | FinHot 只讲 1 个场景；或 Agent 界面 1 个动作 | 转化试探 |

### 3.2 A 型（Deep Fomo）冷启动改版规则

现有 anim7 / kit **能用骨架，须改运营参数**：

1. **时长**：优先 20–30s；长报告只取「钩子 3s + 思考 2 条 + 1 个结论段 + 免责」  
2. **开场三选一**（轮换测）：  
   - 结论前置（anim7 大字）  
   - 情绪 face-hook（深夜盯盘，已有变体思路）  
   - 反差句（「强板块弱个股，先别急着下结论」）  
3. **结尾 CTA（冷启动）**：  
   - ✅「你复盘时先看盘面还是先看公司？」  
   - ✅「这种结构语言你听过吗？」  
   - ❌「评论区报票 / 深挖+股票名」（等有信任与合规话术后再谈）  
4. **合规固定字幕**（全片或片尾）：  
   `案例演示 · 非投资建议 · 不构成买卖依据`  
5. **数据**：只发**当日或明确标注日期**的真实 Agent 输出；过期汇成样板禁止当新内容发  
6. **个股名**：起号前 10 条尽量少点具体票，或明确「历史样本框架演示」；优先讲**框架**（证据硬度表、生命周期四问）再讲票

### 3.3 B 型选题池（桥接 FinHot，不先卖）

1. 一天 8 个 App 刷财经，有效信息有多少  
2. 多看资讯 ≠ 更会投资  
3. 资讯怎么分层：必看 / 可选 / 噪音  
4. 英文来源怎么 5 分钟抓重点（自然引出摘要/中译）  
5. 公告 / 互动易 / 热闹，谁先谁后

## 6. 风险与红线

1. Deep Fomo 内容最容易被平台/监管看成**变相荐股** → 框架演示优先、案例历史化、免责声明固定。  
2. CTA「报票」冷启动禁用。  
3. FinHot 60s 整片冷启动禁用。  
4. 过期样板数据禁止当「今天研究」发布。  
5. 策略收益、跟单、稳赚话术永久禁止。
