# 钩子 Playbook（黄金 3 秒）

as-of: 2026-07-10  
假设用户所说「koi」= **钩子**（短视频开头抓注意力的技巧）。若指 KOL 运营，见文末「KOL 补充」。

## 为什么重要

- 用户划走决策极快；前 3 秒决定是否继续看，进而影响完播与初始池晋级。
- **完播是入场券，不是终点**：还要互动（赞/评/转/关）才能进更大池。
- 钩子必须和后文兑现；「骗点进来」会伤账号标签。

## 十大钩子类型（通用）

| # | 类型 | 公式 | 适合我们？ |
|---|------|------|------------|
| 1 | 引发好奇 | 为什么 / 怎么办 / 如何… | ✅ |
| 2 | 直击痛点 | 具体场景 + 负面结果 | ✅ 主推 |
| 3 | 放大焦虑 | 学不会 X 就永远… | ⚠️ 轻用，金融忌恐吓 |
| 4 | 价值展示 | 价值 N 的方法，码住 | ✅ 量化时间收益 |
| 5 | 抛出利益 | 有了 X 再也不用 Y | ✅ 效率工具向 |
| 6 | 巧用数字 | 99% / 8 个 App / 2 小时 | ✅ |
| 7 | 警告避坑 | 千万别 X，否则 Y | ✅ 起号避坑类 |
| 8 | 借势权威 | 某某都在用的… | ⚠️ 慎用，易违规感 |
| 9 | 内幕揭秘 | 揭秘不为人知的… | ❌ 金融慎用（像荐股黑话） |
| 10 | 反向输出 | 多看资讯 ≠ 更会投资 | ✅ 主推 |

来源综合：迅课「十大钩子」、知识付费三秒钩子三类（痛点 / 价值前置 / 场景代入）。

## 三类高转化结构（知识/工具号）

1. **痛点直击**：具体场景 + 负面结果 → 第 4 秒给「1 个方法」预期  
2. **价值前置**：看完你能得到什么（可量化时间/步骤）  
3. **场景代入**：真实桌面/信息流画面 + 情绪 →「我当时怎么处理」

## FinHot / 金融 Agent 改写示例

| 类型 | 前 3 秒口播 | 禁止写法 |
|------|-------------|----------|
| 痛点 | 「早上打开雪球、微博、RSS、公众号……一看就中午了。」 | 「用我们产品稳赚」 |
| 数字 | 「一天 8 个 App 刷财经，有效信息不到 10%。」 | 「保证收益」 |
| 反向 | 「多看资讯，不会让你更会投资。」 | 「内幕消息」 |
| 避坑 | 「新号第一条千万别发产品介绍。」 | 夸大算法内幕 |
| 价值 | 「3 分钟讲清：怎么给一条新闻打质量分。」 | 「全网最全」空话 |
| 场景 | 录屏：信息流爆炸 → 字幕「信息过载」 | 功能清单 PPT |

## 写作检查清单（发前 10 秒）

- [ ] 前 3 秒有**可搜索词**（财经资讯 / 信息过载 / AI 摘要…）
- [ ] 没有自我介绍式开场（「大家好我是…」）
- [ ] 钩子与后文方法一一对应
- [ ] 结尾是**问题**不是「求关注 / 下载」
- [ ] 时长 15–35 秒时，中段无水词

## KOL 补充（若 koi = KOL）

产品号前期**不要学大 KOL 人设包装**，学的是：

- 垂直标签稳定（算法认人）
- 评论区运营当「用户调研」
- 信任先于曝光（有产品时尤其）

自己产品变现号：用内容测试痛点 → 等用户主动说诉求 → 再做软植入。
