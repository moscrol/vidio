# AI 辅助内容流水线

as-of: 2026-07-10  
目标：日更「及格线以上」——路人愿意转粉、粉丝愿意问工具；不赌每条爆。

## 流水线总览

```
灵感（语音备忘 / 评论 / 对标）
  → 转写
  → Agent 提取标题 + 3 秒钩子（对照 hooks-playbook）
  → 人工用自己的话重说一遍（必做，防 AI 腔）
  → 封面大字 1 张
  → 发布 + 30min 回评
  → 数据进 reviews/
  → 每周复盘 1 次改公式
```

参考：创作者「语音笔记 → Agent 标题钩子 → 自己出镜重说」的日更流水线思路。

## 两种产能模式

### 模式 1：真人口播（产品号主推）

- 工具：手机 + 提词 or 短提纲
- AI：只写钩子与结构，不念 AI 全文
- 成本低、信任高

### 模式 2：录屏 + 字幕（FinHot / Agent 演示）

- 工具：系统录屏 + video-use / 剪映
- 或 card-lab / hyperframes 做信息卡
- 适合「工作流」类，不宜第一条就硬推下载

### 模式 3：长内容拆条

- 1 篇研究长文 / 1 次直播 → 抽 5～10 条短视频
- 每条独立钩子 + 独立结尾（不要「上集下集」依赖）
- Prompt 模板：

```
分析这个长脚本，提取 N 个独立短视频。
每个：独立钩子、完整开头和结尾、15–35 秒、金融合规（不荐股）。
脚本：…
```

## 对标拆解流程（资产化）

1. 收藏 10 个同赛道低粉高赞样本（近 30 天）
2. `douyin-transcript` 出讲稿
3. 只归档**前 5 秒 + 结尾 CTA 类型**到 `ops/douyin/assets/hook-library.md`（待建）
4. 禁止整段搬运；只学结构

## 周节奏建议

| 日 | 动作 |
|----|------|
| 日更 | 发 1 条 + 填简版数据 |
| 每周日 | 复盘 3 条最好 / 3 条最差；改下周一钩子实验 |
| 每双周 | 补 5 条对标钩子进库；更新 skills-catalog |

## 及格线定义（我们自己的）

- 完播与评论不低于你近 7 条中位数  
- 出现至少 1 条有效评论（问题/共鸣，不是表情包）  
- 无违规、无硬广反感
