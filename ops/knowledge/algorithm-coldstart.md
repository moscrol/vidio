# 冷启动与推流（工作假设）

as-of: 2026-07-10  
说明：以下为公开运营者经验 + 二手解读的**工作假设**，非抖音官方白皮书。用于决策，定期用我们自己的数据校正。

## 三层模型（常见说法）

```
冷启动试探（约几百～千级曝光）
    ↓ 完播 / 互动达标
更大流量池（赛马）
    ↓ 持续表现
长尾 / 搜索 / 相关推荐
```

- 首条硬广（产品介绍）完播与互动通常双杀 → 试探失败 → 次日接近 0 推。
- **新号 0 粉 + 仅 1 条失败内容**：换号成本低；失败标签主要来自内容，不必然是设备级封禁。

## 指标优先级（起号期）

| 优先级 | 指标 | 备注 |
|--------|------|------|
| P0 | 3s/5s 留存、整体完播 | 入场券 |
| P0 | 评论率 | 比点赞更强信号 |
| P1 | 关注率 | 人设是否成立 |
| P2 | 绝对播放量 | 短期别焦虑 |
| 避 | 挂外链 / 硬广转化 | 易进商家池或限流 |

经验区间（仅作方向，非 KPI 合同）：

- 短片 ≤15s：完播尽量冲高  
- 15–35s：结构紧、少铺垫  
- 更长：必须中段再钩（否则后半崩完播）

## 起号动作清单

**养号 1–2 天**

- 刷同赛道（AI 工具 / 财经效率 / 独立开发）
- 认真评论（有观点）
- 资料垂直、无下载硬广

**前 5～15 条**

- 100% 垂直价值内容
- 0 外链、0 功能清单
- 发布后 30 分钟内回评
- 标题/口播/封面埋搜索词

**失败信号 → 动作**

| 信号 | 动作 |
|------|------|
| 仅个位数播放、连续多条 | 停 1 天；查违规；改钩子与封面 |
| 有播放无互动 | 加结尾问题；降低信息密度 |
| 有完播无关注 | 人设不清晰；加「我是谁在解决什么」一句（非产品名） |
| 挂链后暴跌 | 立刻去链；回价值内容 |

## 产品型账号特殊规则

1. 有产品时，**痛点未知** → 必须用内容做测试，等用户在评论区「自己说」。
2. 虚拟产品 / 外链敏感：前期不挂；火后再考虑挂载方式。
3. 三种内容能力模型不同：纯流量 / 甲广 / **自有产品**——我们是第三种，前期难、后期资产可复用。

## 金融赛道额外风控

- 荐股、稳赚、跟单、内幕、AI 预测大盘 → 限流 + 合规风险  
- 定位锁定在：**信息效率、研究工作流、工具方法**
