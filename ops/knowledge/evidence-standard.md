# 顾问建议 · 证据标准（短视频）

as-of: 2026-07-11  
目的：你要求「建议有权威佐证（如 KOL 验证过）、标题尽量有统计学依据」。本文件规定顾问**可以说什么、怎么标注、什么算验证**。

---

## 1. AI HOT Skill 能用于创作吗？

| 用途 | 是否适用 | 说明 |
|------|----------|------|
| 追 **AI 行业事实**（模型/产品/论文/技巧观点） | ✅ | 公开 API，比训练数据新；tutor 号选题弹药 |
| 把热点改成 **tutor 片钩子**（「今天大家都在谈 X，但底层是…」） | ✅ | 热点 = 时效钩子；原理仍来自 70_tutor |
| **抖音算法 / 完播 / 标题公式** | ❌ 几乎不适用 | 实测：`q=抖音/完播/钩子` 精选池 **0 条**；AI HOT 不是短视频运营数据库 |
| **标题 CTR 的统计验证** | ❌ | 不含创作者中心 A/B 或大盘标题实验数据 |
| **某 KOL 操盘手背书的 douyin 话术** | ❌ 非其定位 | 要用对标拆解 / 公开复盘 / 你自己数据 |

**一句话**：AI HOT 是 **「讲什么（AI 事实与观点）」** 的信源，不是 **「抖音标题怎么写才涨」** 的信源。

## 2. 证据等级（强制标注）

每条可执行建议（选题、标题、钩子、时长）在脚本/复盘里应带等级：

| 等级 | 含义 | 示例来源 | 顾问话术 |
|------|------|----------|----------|
| **L0 假设** | 无外部验证，逻辑外推 | 顾问结构判断 | 「建议先试，未验证」 |
| **L1 案例** | 单个创作者/单条公开说法 | 某博主复盘帖、单条 X | 「据 X 称…样本=1」 |
| **L2 多源共识** | ≥3 个独立从业者同方向，方法可复述 | 多篇运营复盘 + 你对标拆解 | 「多源方向一致，非严格统计」 |
| **L3 平台/机构材料** | 官方文档、巨量课堂、平台公开报告 | 巨量算数、创作者学院 | 「平台口径/行业报告」 |
| **L4 自有统计** | 你账号上的对照或累积 | `reviews/` A/B、同结构 N≥10 | 「我号上完播/CTR 差 Δ」 |
| **L5 正式实验** | 预注册假设、样本量、显著性 | 同号同时段 A/B、足够曝光 | 「统计显著 / 置信区间」 |

**默认承诺**：

- 起号前 **几乎没有 L4/L5**（新号无历史）。  
- 外部运营文多数是 **L1–L2**，**不得假装 L5**。  
- 标题「经过统计学验证」——在没做你自己的实验前，**只能说「候选假设 + 对标样本结构」**，不能说「已被证明最优」。

## 3. 什么叫「被 KOL 证实」

收紧定义，避免营销号自嗨：

**算佐证（弱→中）**

1. 可核验身份的创作者，在 **可追溯链接** 里描述可复现动作（不是「私密圈保证」）。  
2. **结果可观察**：公开主页播放/粉丝趋势与说法大致同向（仍可能有幸存者偏差）。  
3. **方法具体**到可拍：钩子句式、时长、结构，而非「真诚就有流量」。

**不算**

- 无来源的「业内都知道」  
- 卖课页恐吓式数据（「不用这个完播必挂」）  
- 刷量/代运营灰产话术  

记录位置：`ops/knowledge/sources.md` + 脚本 frontmatter `evidence:` 字段。

## 4. 标题建议怎么才「像统计」

### 4.1 诚实边界

平台标题/封面文案的「最优」依赖：赛道、时段、封面图、账号权重。  
**没有普适、可迁移的「全国最优标题公式」公开数据集。**  
顾问给标题时默认流程：

```
候选标题 3–5 条
  → 每条标注：句式类型 + 证据等级 + 对标样本（若有）
  → 发布后写入 reviews：曝光、完播、点赞、评论、关注
  → 同结构累积 ≥10 条后再做「我号上的」排序（升 L4）
```

### 4.2 起号期可用的「准统计」做法（推荐）

| 方法 | 做什么 | 等级 |
|------|--------|------|
| **对标结构采样** | 同赛道近 30 天、低粉高赞 Top N，拆标题句式频次 | L2（描述性统计，非因果） |
| **句式桶** | 否定句 / 反问 / 数字 / 对比 / 结果前置 分桶测 | L0→L4（测完升） |
| **单变量实验** | 同视频只改标题或只改封面大字，隔天对照难；优先 **连续条同结构轮换句式** | L4 弱设计 |
| **站内搜索词** | 标题含用户会搜的词（Agent/防幻觉/…） | L3 若来自平台搜索建议 |

### 4.3 标题交付模板（顾问必用）

```markdown
### 标题候选
1. 「…」  
   - 句式：否定/反问/…  
   - 证据：L0–L5 + 来源链接或「自有 reviews #」  
   - 假设：提高 3s 留存 / 搜索曝光 / 评论  
2. …
推荐先发：#k（理由一句话，不夸大）
```

禁止：不标注等级却写「数据证明」「全网验证」「统计学显著」。

## 5. 推荐工作流（权威感从哪来）

```
选题（70_tutor 概念）
    │
    ├─ 时效钩子（可选）← AI HOT 精选/热点/技巧  【行业事实 L3 级信源】
    │
    ├─ 结构与钩子类型 ← hooks-playbook + 对标 N 条  【L1–L2】
    │
    ├─ 标题 3–5 候选 ← 句式桶 + 证据标注  【起号期多为 L0–L2】
    │
    └─ 发布 → reviews → 句式胜率表  【升 L4，这才是「你的统计」】
```

**KOL 角色**：对标采样对象，不是信仰。  
**AI HOT 角色**：tutor 内容的事实与热点佐证。  
**统计角色**：以你号 `reviews/` 为最终法庭。
