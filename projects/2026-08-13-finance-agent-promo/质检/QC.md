## 真问题（不挡挑风格，定稿前要改）

1. **v02 免责声明太短**  
   `#b8-disc` 28.9s 淡入，`#b8` 29.45s 开始淡出。合规句在画面上不到 1 秒。定 v02 的话把声明提前到 CTA 入镜，并取消末 0.5s 整镜黑场，或声明单独留到 30.0s。

2. **多版末 0.55s 整镜淡出**  
   v02 / v03 / v05 / v07 / v08 / v09 都在 29.45s `opacity: 0`。抖音末帧会被截成封面时，可能截到半透明 CTA。建议定稿版把淡出去掉，或只压 BGM。

3. **事实仍是占位**  
   「你的金融 Agent · 名称占位」、指令「查一下今天新能源板块异动的原因」、用时 1'42"、三条结论，全部是 DEMO。brief 里待补的 5 条事实没变。

4. **v01 工程偏重**  
   单文件 + 重叠加，以后改某一镜成本高。定 v01 再拆 `compositions/`。
