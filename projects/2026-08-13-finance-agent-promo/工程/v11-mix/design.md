# design.md — v11 混剪

本版不重画界面，只剪已渲成片。叠加层必须薄，不能盖住各版自己的字。

## Palette（叠加层）

- flash: `#F2F0EB`（切点 3 帧砸切）
- rgb-r: `#E5484D`
- rgb-g: `#3DD68C`
- rgb-b: `#0066FF`
- grain: 黑白噪点 12% 不透明度，全片钉住，把十种材质缝成一条片子
- accent: `#FFD60A`（只给切点扫描线，不进字幕）

## Typography

叠加层无标题、无风格名、无「v02」角标。叙事字全部来自源片。

## Motion

- 节奏：`SMASH-SMASH-HOLD-HOLD-SMASH-hold`
- 镜间：硬切 + 3 帧闪光 + RGB 位移（不是淡出、不是溶解）
- 产品入场（10.0s → v06）是唯一加重 glitch（6 帧）
- 源片 BGM 全部剥掉，全片一条 `tonight-hiphop`

## 约束

- 1080×1920 · 30s · 30fps · 无人出镜 · 无配音
- 末 3 秒必须看见 CTA 与「不构成投资建议」（取 v10 27–30s）
- 演示数据仍是占位
