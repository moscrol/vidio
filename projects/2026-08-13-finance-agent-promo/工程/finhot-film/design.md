## 设计系统（全片唯一，解决「色调不一致」；R10 按用户要求改做旧纸张 + 毛玻璃）

- 底色：做旧纸张 `#EDE2CB`——root 级共享层：陈渍径向斑 + multiply 纤维噪点 +
  暖褐晕影（纸张老化边缘）+ 三枚暖色 blob（供毛玻璃折射）
- 强调色：烧橙 `#E8590C`（FinHot 橙在纸底上的高对比档），墨色文字 `#33291C`
  带 1px 纸白浮雕 text-shadow
- 组件统一毛玻璃配方：`rgba(255,251,242,0.42)` + `backdrop-filter: blur(18px)
  saturate(1.2)` + 1.5px 白描边 + 暖褐投影 + inset 高光——信源芯片 / 功能芯片 /
  字幕底板 / CTA 芯片全用同一配方；截图卡用半透明纸白「相框」边
- 文字：Noto Sans SC 700 大字 / JetBrains Mono 角签；角签全片同格式
  `FINHOT · <SECTION>`（左上）+ 状态（右上）
- 真实 UI 为白卡浮在纸底上，玻璃组件浮在两者之间——三层材质深度

## 转场语言（全片唯一，解决「转场生硬」）

**信息流式竖推**：上一镜整体上推离场、下一镜从下方推入（出 0.72s power2.inOut /
入 0.78s power2.out，进出重叠；R11 由 0.5s power3 放柔），动机 = 「刷信息流」
的产品隐喻。白闪全片只有 1 次，钉在 26.859s 发布会合影落定的收束拍上（Q4）。
