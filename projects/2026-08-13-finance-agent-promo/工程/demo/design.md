# design.md — 金融 Agent 宣传 demo

## Palette（Dark/Premium · 海军蓝+金）

- bg: `#000814`（全片统一背景）
- panel: `#001D3D`（卡片/窗口底）
- panel-2: `#003566`（次级面板、描边）
- fg: `#E8EEF7`（正文，向蓝微调）
- fg-dim: `#8FA3BD`（次级文字）
- accent: `#FFC300`（金，焦点/按钮/勾选）
- accent-2: `#FFD60A`（金亮，高光）
- danger: `#E5484D`（压力红，仅镜头 1–2）
- ok: `#3DD68C`（完成绿，勾选辅助）

## Typography

- Hero/金句: "Noto Serif SC", serif · 700–900
- UI/正文: "Noto Sans SC", "WenQuanYi Micro Hei", sans-serif · 400–700
- 行情/代码: "JetBrains Mono", monospace

## Motion

- 能量：medium（8.7s 前 tense 尖峰，产品出场后转 calm-confident）
- 主转场：push（vertical push / push slide）；重音：glitch（钩子→洪流）、
  blur crossfade（洪流→产品，情绪转折）、color dip（收尾）
- 全片无人出镜；紧张感由光标、窗口堆叠、红色脉冲承载

## 约束

- 演示界面数据全部为占位示例，右下角常挂「演示数据」声明；结尾挂
  「不构成投资建议」
- 不用青紫渐变、渐变文字；金色是唯一主强调色
