# Publish Editing Template

用途：定义 Industry 7View 短视频发布版的剪辑结构。Remotion 输出的卡片视频不是最终发布版，最终成片应结合 A-roll、B-roll、动态图文卡、字幕、音效和封面。

## 1. 发布版结构

```text
A-roll / 数字人口播
+ B-roll
+ Remotion 动态图文卡
+ 字幕
+ 音效
+ 封面
```

目标不是展示所有卡片，而是让观众在 60-75 秒内听懂一个产业判断。

## 2. 推荐时间结构

| 时间段 | 画面主导 | 目的 | 卡片建议 |
|---|---|---|---|
| 0-3s | A-roll / 强 B-roll / CoverCard | 抓住注意力 | 可选 1 张 |
| 3-15s | A-roll + B-roll + Compare | 纠偏或抛出冲突 | 0-1 张 |
| 15-35s | B-roll + Logistics / BusinessLoop | 解释结构和路径 | 1 张 |
| 35-50s | DataHero / Checklist + B-roll | 给数字或跟踪变量 | 1 张 |
| 50-75s | A-roll + ClosingQuote | 收束观点和互动 | 0-1 张 |

整条视频通常只需要 3-5 张卡。

## 3. 剪映轨道建议

```text
轨道 1：A-roll / 数字人口播主视频
轨道 2：B-roll 覆盖画面
轨道 3：Remotion 卡片 / PNG / 动态图文
轨道 4：主字幕
轨道 5：关键词强调字幕
轨道 6：音效
轨道 7：BGM
```

轨道原则：

```text
1. A-roll 是叙事主轴，不要被卡片长期盖住。
2. B-roll 用于替换或覆盖 A-roll 的弱画面段落。
3. 卡片只在需要结构化理解时出现。
4. 字幕永远服务口播，不要和卡片大段重复。
```

## 4. 0-3 秒开头模板

目标：让观众立刻知道“这条视频和我原来的理解不一样”。

可选结构：

```text
A. A-roll 强判断 + 大字幕
B. 强 B-roll + 口播强判断
C. CoverCard 1-2 秒 + A-roll 接入
```

不建议：

```text
1. 上来就堆产业链。
2. 上来就放公司名单。
3. 上来就放 5 秒以上卡片静帧。
```

## 5. 3-15 秒冲突段

适合内容：

```text
1. 大众误解 vs 真正变量。
2. 技术热闹 vs 商业兑现。
3. 概念炒作 vs 产业约束。
```

画面组合：

```text
A-roll 讲判断
+ B-roll 给反例或真实场景
+ CompareMotion 短暂上屏
```

剪辑规则：

```text
Compare 卡不要超过 5-8 秒。
解释句过长时，让口播讲，卡片只放关键词。
```

## 6. 15-35 秒结构段

适合内容：

```text
1. 行业怎么运转。
2. 商业闭环怎么形成。
3. 技术系统由哪些环节组成。
```

画面组合：

```text
B-roll 为主
+ LogisticsCard 或 BusinessLoopMotion
+ 少量关键词字幕
```

剪辑规则：

```text
1. BusinessLoop 出现前先用 B-roll 建立场景。
2. 节点动画结束后尽快切回真实场景。
3. 如果一个闭环段超过 12 秒，中间必须穿插 B-roll。
```

## 7. 35-50 秒证据段

适合内容：

```text
1. 一个核心数字。
2. 一个验证进展。
3. 三个跟踪指标。
```

画面组合：

```text
DataHeroMotion / TrackingChecklistCard
+ 相关 B-roll
+ 数字字幕强调
```

剪辑规则：

```text
1. 一张 DataHero 只放一个主数字。
2. Checklist 优先三条，不要四条以上。
3. 证据墙通常作为备用素材，不强行进主时间线。
```

## 8. 50-75 秒收束段

适合内容：

```text
1. 结论金句。
2. 后续跟踪提醒。
3. 评论区互动。
4. 主站引导。
```

画面组合：

```text
A-roll 回切
+ ClosingQuote 或大字幕
+ 轻 B-roll 情绪收束
```

结尾句式：

```text
1. 所以这门生意，不是看 X，而是看 Y。
2. 真正要跟踪的，不是热度，而是兑现。
3. 你觉得它会先在哪个环节兑现？评论区聊聊。
```

## 9. 字幕规范

主字幕：

```text
1. 跟随口播。
2. 每行尽量短。
3. 不要遮挡卡片核心数字。
```

强调字幕：

```text
1. 只强调关键词、数字、判断。
2. 不要每句话都加花字。
3. 颜色与 Industry 7View token 保持一致：深蓝、金色、白色、浅灰。
```

## 10. 音效和 BGM

BGM：

```text
克制、科技、研究感，不要过强情绪煽动。
```

音效：

```text
1. 卡片入场：轻微 click / whoosh。
2. 数字出现：短促 pop。
3. 节点点亮：soft tick。
4. 结尾金句：轻微低频收束。
```

不建议：

```text
1. 高频炸裂音效。
2. 过度综艺化音效。
3. BGM 压过口播。
```

## 11. 发布前检查清单

```text
[ ] 前 3 秒是否有强判断。
[ ] 60-75 秒内是否只讲一个问题。
[ ] 卡片数量是否控制在 3-5 张。
[ ] 是否有连续 8 秒以上画面缺少变化。
[ ] 是否有连续两张以上重信息卡导致疲劳。
[ ] B-roll 是否真实服务口播。
[ ] 字幕是否遮挡卡片或脸部。
[ ] 是否出现无授权 logo 或错误文字。
[ ] 结尾是否有金句、互动或主站引导。
[ ] 是否保留风险提示或“不构成投资建议”。
```
