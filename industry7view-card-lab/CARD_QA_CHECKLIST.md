# Industry 7View Card QA Checklist

这份清单用于 `npm run check` 之后的人工视觉验收。自动校验只负责字段和结构，不能替代视觉判断。

## 1. 全局检查

- [ ] 是否生成到 `output/{slug}/`，没有覆盖其他主题。
- [ ] 是否共有 8 张 PNG：1 张封面 + 7 张正文卡。
- [ ] 是否保持 9:16 竖屏。
- [ ] 是否保持深蓝、金色、浅纸底、直角、网格背景。
- [ ] 是否没有出现内部路径、raw、Obsidian、个人数据库称呼。
- [ ] 是否保留必要的“不构成投资建议”。

## 2. 单卡检查

### 00 CoverCard

- [ ] 是否像信息流封面，而不是正文解释页。
- [ ] 标题是否一眼能读懂。
- [ ] 副标题是否尽量一行显示。
- [ ] 是否没有内部路径和过长链接。
- [ ] 是否适合作为抖音/B站封面或开场主视觉。

### 01 HookCard

- [ ] 3 秒内能否看懂核心判断。
- [ ] 标题是否只讲一个判断。
- [ ] `≠` 或反常识表达是否清楚。
- [ ] 高亮词是否没有换行尴尬。

### 02 DataHeroCard

- [ ] 数字是否是全卡最大视觉锚点。
- [ ] 单位是否横排、清楚、不挤压。
- [ ] `label` 是否解释“这个数字是什么”。
- [ ] `compareText` 是否提供对比基准。
- [ ] `insight` 是否说明数字的产业意义。
- [ ] 是否避免“大数字即结论”的误导。

### 03 LogisticsCard

- [ ] 类比是否准确。
- [ ] 是否能降低理解门槛。
- [ ] 是否没有为了有趣牺牲严谨性。

### 04 CompareCard

- [ ] 左右两侧是否短促有力。
- [ ] 左侧是否是大众误解。
- [ ] 右侧是否是真正变量。
- [ ] `explain` 是否补足逻辑但不抢主视觉。

### 05 BusinessLoopCard

- [ ] 步骤是否为 3-5 个。
- [ ] 每个节点是否是短语而不是长句。
- [ ] 最后一步是否落到兑现变量。
- [ ] 是否需要比普通卡停留更久。

### 06 TrackingChecklistCard

- [ ] 是否是可收藏清单。
- [ ] 每项是否可观察、可跟踪。
- [ ] 是否避免“景气度好、前景广阔”等泛词。

### 07 ClosingQuoteCard

- [ ] 是否像一句可截图传播的结论。
- [ ] 主站链接是否正确。
- [ ] 风险提示是否清楚。
- [ ] 标题换行是否自然。

## 3. 剪映检查

- [ ] 每张卡是否至少停留 2.5 秒。
- [ ] DataHeroCard 是否根据数据复杂度停留 3-4 秒。
- [ ] BusinessLoopCard 是否停留足够久。
- [ ] 字幕是否挡住主标题或大数字。
- [ ] B-roll 是否过度科幻或像素材库广告。
- [ ] BGM 是否压过口播。
- [ ] 音效是否克制。
- [ ] 全片是否保持 Industry 7View 的克制研究感。

## 4. 失败处理

```text
如果字段校验通过但视觉不舒服：优先改文案，不先改布局。
如果 2-3 个主题都出现同一问题：记录到 COMPONENT_BACKLOG.md。
如果只是单条视频的节奏问题：记录到剪映清单，不进入组件库。
```
