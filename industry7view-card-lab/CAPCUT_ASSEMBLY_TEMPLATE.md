# Industry 7View 封面 + 七卡剪映装配模板

用途：把 `industry7view-card-lab/output/{slug}/` 导出的 1 张封面 + 7 张正文 PNG，与数字人/真人口播、B-roll、字幕、音效装配成 60-75 秒短视频粗剪。

这份模板是通用版，不绑定具体主题。单条视频只替换主题、口播、B-roll 和互动问题。

## 1. 素材准备

### 1.1 封面 + 七张图文卡

位置：

```text
/Users/lbq/Desktop/c c/视频/industry7view-card-lab/output/{slug}/
```

需要导入：

```text
00-cover-card.png
01-hook-card.png
02-data-hero-card.png
03-logistics-card.png
04-not-a-is-b.png
05-business-loop.png
06-tracking-checklist.png
07-closing-quote.png
```

`00-cover-card.png` 主要用于发布封面、B站封面、抖音图文封面，也可作为视频开场 0-2 秒主视觉。正文剪辑节奏仍以 01-07 为主。

使用规则：

```text
如果平台允许单独上传封面：00-cover-card.png 只做封面，不进时间线。
如果平台不方便单独设封面：00-cover-card.png 可放在开头 0-2 秒。
01-hook-card.png 才是正式正文第一张卡，负责承接口播开头。
```

### 1.2 口播素材

任选一种：

```text
A. 剪映数字人口播
B. 真人口播视频
C. AI 配音音频
```

建议口播稿来源：

```text
/Users/lbq/Desktop/c c/视频/抖音/{主题}_抖音短视频组.md
或对应分镜执行表第 2 节“压缩口播稿”
```

### 1.3 B-roll 素材

最低配置：

```text
2-3 段 B-roll，每段 4-8 秒。
```

优先放在：

```text
03 LogisticsCard 后
05 BusinessLoopCard 后
06 TrackingChecklistCard 前后
```

如果没有 B-roll，可以先只用 PNG + 数字人口播完成粗剪。

## 2. 剪映项目设置

```text
画布比例：9:16
分辨率：1080×1920
帧率：30fps
格式：MP4
```

## 3. 推荐轨道结构

```text
轨道 1：数字人/真人口播主视频
轨道 2：B-roll 视频
轨道 3：PNG 图文卡
轨道 4：字幕
轨道 5：音效
轨道 6：BGM
```

记住：

```text
口播在底层
B-roll 和 PNG 盖在口播上
字幕再盖在最上面
音效和 BGM 放音频轨
```

## 4. 七卡推荐时间线

适合 60-75 秒视频。

| 时间 | 画面 | 素材 | 作用 | 建议动画 | 音效 |
|---|---|---|---|---|---|
| 0-3s | 开头钩子 | `01-hook-card.png` | 反常识判断 | 淡入 0.2s，100%→104% | 低频冲击 |
| 3-7s | 数据冲击 | `02-data-hero-card.png` | 给证据锚点 | 淡入，数字处可轻微放大 | whoosh / click |
| 7-12s | 类比解释 | `03-logistics-card.png` | 降低理解门槛 | 右侧轻微滑入或淡入 | whoosh |
| 12-18s | 误区纠偏 | `04-not-a-is-b.png` | 误解 vs 真相 | 淡入，整体 100%→103% | 关键词重击 |
| 18-30s | 路径/闭环 | `05-business-loop.png` | 讲主逻辑 | 下方上移 20px + 淡入 | 节点 click |
| 30-44s | B-roll / 场景解释 | B-roll | 承接口播细节 | 硬切 / 淡入 | 轻 click |
| 44-56s | 跟踪清单 | `06-tracking-checklist.png` | 可收藏框架 | 淡入，100%→103% | 三次 click |
| 56-66s | 结论金句 | `07-closing-quote.png` | 收束观点 | 慢推近 100%→106% | BGM 短停 + 低频重击 |
| 66-75s | 互动收尾 | 真人/数字人或结尾卡停留 | 评论引导 | 静止或轻推近 | BGM 渐弱 |

## 5. 最低可交付版本

如果时间紧，只做：

```text
0-3s：01-hook-card.png
3-7s：02-data-hero-card.png
7-12s：03-logistics-card.png
12-18s：04-not-a-is-b.png
18-30s：05-business-loop.png
30-44s：数字人口播或 B-roll
44-56s：06-tracking-checklist.png
56-66s：07-closing-quote.png
66-75s：互动收尾
```

所有 PNG 只加：

```text
淡入
轻微放大
```

这就足够做第一版粗剪。

## 6. 字幕规则

### 6.1 自动字幕

```text
1. 选中口播音频或视频。
2. 使用剪映“智能字幕 / 识别字幕”。
3. 生成后检查错别字。
4. 字幕放底部，但不要挡住图文卡主标题。
```

### 6.2 字幕样式

```text
字体：剪映默认黑体 / 思源黑体 / 粗体
颜色：白色
关键词：金色或黄色
描边：深蓝或黑色
每行字数：不超过 16-18 个汉字
```

图文卡出现时，可以减少完整字幕，只保留关键词。

## 7. BGM 和音量

### 7.1 BGM 类型

剪映搜索：

```text
科技感
纪录片
电子
工业
未来感
冷静
商业
```

不要选：

```text
太燃的影视预告片音乐
太吵的 EDM
太情绪化的悲伤音乐
短剧感音乐
```

### 7.2 音量建议

```text
口播音量：100%
BGM 音量：15%-25%
B-roll 原声：0%-20%，多数时候静音
音效：30%-50%
```

如果听不清口播，优先降低 BGM。

## 8. 转场原则

只用：

```text
硬切
淡入淡出
轻微推近
轻微滑入
```

不要用：

```text
旋转
翻页
碎片
炫光
漫画转场
强烈故障风
```

原因：Industry 7View 的风格是克制、研究感、可信，不是短剧和娱乐剪辑。

## 10. 粗剪验收清单

导出前检查：

- [ ] 开头 3 秒是否能看懂核心判断。
- [ ] DataHeroCard 的数字和单位是否一眼可读。
- [ ] 每张卡是否至少停留 2.5 秒。
- [ ] BusinessLoopCard 是否停留足够久。
- [ ] 字幕是否挡住卡片主标题或大数字。
- [ ] 口播是否听得清。
- [ ] BGM 是否太吵。
- [ ] B-roll 是否过度科幻或像素材库广告。
- [ ] 结尾是否有互动问题。
- [ ] 是否保留“不构成投资建议”。
- [ ] 全片是否保持 Industry 7View 的克制研究感。

## 11. 第一版目标

第一版粗剪的目标不是发布，而是验证：

```text
七卡放进视频里是否舒服
口播和图文卡节奏是否匹配
B-roll 是否需要增加或减少
用户能不能一眼看懂核心观点
```

粗剪 OK 后，再考虑把高复用段落转成 Remotion / HyperFrame 动效模板。
