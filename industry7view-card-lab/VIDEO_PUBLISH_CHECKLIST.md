# Video Publish Checklist

用途：把 `output/video/card-deck-with-talk.mp4` 从工程样片推进到可发布样片，避免只验证命令通过、但忽略抖音/B站真实观看体验。

## 1. 当前发布候选

```text
主题：人形机器人第一条
视频：output/video/card-deck-with-talk.mp4
口播：public/0510-2.mov
字幕：public/0510-2(1).srt
时间线：motion-plan.json
规则：timeline-rules.json
状态：Publish candidate v1
```

## 2. 发布判定

```text
Pass：可以发布。
Needs minor timing tweak：只需要微调 timeline-rules.json 的 offset。
Needs visual tweak：需要重新导出卡片或调整视觉遮挡。
Do not publish：口播、卡片或节奏存在结构性问题。
```

## 3. 必检项

### 3.1 口播与卡片对齐

- 卡片开始时间是否对应口播段落第一句。
- 卡片结束时间是否覆盖口播段落最后一句。
- 卡片是否在下一段口播开始前自然退场。
- 若只差 0.2-0.8 秒，优先改 `timeline-rules.json` 的 `startOffset` 或 `endOffset`。
- 不直接手改 `motion-plan.json` 作为长期方案。

### 3.2 画面遮挡

- 卡片是否遮挡人脸。
- 卡片是否遮挡视频自带字幕。
- 卡片是否遮挡关键手势或 B-roll 重点。
- 底部说明和品牌角标是否仍然可读。

### 3.3 手机端可读性

- 封面标题是否 1 秒内能读完。
- 数据大字是否足够突出。
- 正文卡是否存在字数过密。
- 金色强调是否真正落在重点数字或关键词上。

### 3.4 前 3 秒

- 第一秒是否出现强判断。
- 3 秒内是否让用户知道视频在讲什么。
- 开头是否避免铺垫过长。
- 封面截图是否能单独作为抖音图文封面。

### 3.5 节奏

- 70 秒内卡片切换是否自然。
- 是否存在某张卡停留过久但信息量不足。
- 是否存在某张卡信息量很大但停留过短。
- 结尾是否留出评论互动或关注引导空间。

### 3.6 发布信息

- 标题是否有强判断或反常识。
- 简介是否说明核心观点。
- 标签是否包含主题词、产业词和栏目词。
- 评论区置顶是否引导讨论。
