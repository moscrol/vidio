# Topic To Video Brief Template

用途：在改 `cards.js`、生成 SRT 时间线或剪辑视频之前，先把一个产业主题收敛成可执行的 60-75 秒短视频 brief。它解决的问题是：这条视频到底讲什么、哪里上卡、哪里留给 A-roll / B-roll。

## 1. 基本信息

```text
主题：
主站链接：https://industry7view.com/research/{slug}/
视频标题：
适合时长：60-75 秒
目标平台：抖音 / B站 / 视频号 / 小红书
口播稿路径：
SRT 路径：
口播视频路径：
```

## 2. 一句话判断

```text
这条视频只回答一个问题：

____。
```

写作要求：

```text
1. 只保留一个核心判断。
2. 不要同时讲行业科普、投资逻辑、公司名单和风险矩阵。
3. 能用“不是 A，而是 B”表达时优先使用。
```

## 3. 3 秒钩子

```text
开头 0-3 秒口播：

____。
```

可用句式：

```text
1. 很多人以为 X，其实真正的变量是 Y。
2. 这个行业最重要的不是 X，而是 Y。
3. 如果只看 X，你可能看反了。
4. 这门生意能不能成立，关键看三件事。
```

对应画面建议：

```text
A-roll / CoverCard / 强 B-roll / 轻字幕
```

## 5. 卡片选择

60-75 秒视频通常只选 3-5 张卡。

| 卡片 | 是否使用 | 对应口播 | 使用理由 | 是否必须上屏 |
|---|---|---|---|---|
| CoverCard | 是/否 |  |  |  |
| DataHeroMotion | 是/否 |  |  |  |
| CompareMotion | 是/否 |  |  |  |
| BusinessLoopMotion | 是/否 |  |  |  |
| LogisticsCard | 是/否 |  |  |  |
| TrackingChecklistCard | 是/否 |  |  |  |
| ClosingQuote | 是/否 |  |  |  |
| EvidenceGridCard | 是/否 |  |  |  |

判断规则：

```text
1. 有数字，不等于必须上 DataHero；只有这个数字能支撑主判断才上。
2. 有产业链，不等于必须上 BusinessLoop；只有存在清晰因果或闭环才上。
3. 有公司名单，不等于必须上 EvidenceGrid；短视频主线通常不靠名单推进。
4. 有空白，不等于必须补卡；空白可以留给 B-roll。
```

## 6. B-roll 选择

| 口播段落 | 适合 B-roll | 画面关键词 | 是否需要 AI 生成 | 备注 |
|---|---|---|---|---|
| 0-3s |  |  |  |  |
| 3-15s |  |  |  |  |
| 15-35s |  |  |  |  |
| 35-50s |  |  |  |  |
| 50-75s |  |  |  |  |

优先用 B-roll 的段落：

```text
1. 行业真实场景。
2. 设备、工厂、实验室、火箭、卫星、机器人等具象物体。
3. 情绪判断、反问、停顿。
4. 卡片连续出现后的节奏缓冲。
```

## 7. 时间线草案

```text
0-3s：
3-15s：
15-35s：
35-50s：
50-75s：
```

每段只写三件事：

```text
1. 口播目的。
2. 画面类型。
3. 是否上卡。
```

## 8. 字幕重点

```text
核心字幕 1：
核心字幕 2：
核心字幕 3：
结尾字幕：
```

字幕规则：

```text
1. 字幕只承载短判断，不搬运长句。
2. 公司名、数字、英文缩写可以交给字幕，不一定口播全念。
3. 关键数字出现时，字幕和卡片数字必须一致。
```

## 9. 发布信息

```text
发布标题：
备选标题 1：
备选标题 2：
封面文案：
简介：
标签：
置顶评论：
风险提示：不构成投资建议
```

## 10. 完成标准

这份 brief 合格的标准：

```text
1. 一眼能看出这条视频只讲一个判断。
2. 明确哪些地方上卡，哪些地方不上卡。
3. 明确 B-roll 承担哪些段落。
4. 卡片数量控制在 3-5 张。
5. 没有把研究报告完整搬进短视频。
```
